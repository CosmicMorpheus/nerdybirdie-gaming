# READ ME FIRST — Nerdy Birdie Gaming
Version 1.0 | Founder-approved direction and proposed implementation details | 2026-11-23

## For the founder
1. Extract the entire ZIP into a NEW dedicated project directory, separate from the live COZMC repository. Keep the original archive as a reference.
2. Open that folder in Claude Code (or start Claude Code with that folder as its working directory). Make sure `CLAUDE.md` is at the workspace root. Do not open the live COZMC repo as the build workspace.
3. Copy the entire text of `01_START_CLAUDE_HERE.md` into Claude Code. Keep the files and logo together; Claude should read the files, not just the prompt.
4. Review Claude's proposed stack, scope, visual direction and any missing inputs. Approve the plan before major implementation. Use a separate staging site/branch, not live production. The initial site needs no blockchain or Algorand TestNet.
5. Test the site on your phone while playing. Collect Xbox or other platform screenshots, notes and corrections; use the submission template. Ask Claude to integrate them through the content directory.

## What is included / not included
This is a development starter pack, not a completed or deployed site. There is no verified gameplay database, live Discord invitation, registered domain, game image license grant, credentials, or production access in this archive. Claude should locate existing authorized COZMC links and assets through its available project context; if absent, ask for them or mark them unconfigured. Never guess an invite. Only the supplied Nerdy Birdie logo is bundled as imagery. Other imagery must be researched, rights-checked and approved for its intended use.

**Goal:** deliver useful free gaming tools first, welcome players into COZMC second, and consider sustainable monetization and optional education later. Brick by Brick, WE Build.
