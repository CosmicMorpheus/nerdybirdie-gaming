# Product requirements — v1.0

## Approved direction
Nerdy Birdie Gaming is a standalone site under the Nerdy Birdie brand, starting with GTA VI, then additional games. Eventually link to a central Nerdy Birdie site showcasing the founder's online work (URL TBD). COZMC remains a distinct connected community at https://cozmc.us/. Primary audience: gamers who need useful, quick, trusted information during play, including on phones beside a console. Free guides and basic tracking stay public. Exclusive community features and membership benefits later. Initial editorial contributors: founder and authorized AI teammates; no public self-publishing. Founder gameplay screenshots supplement/replace temporary imagery; founder captures initially on Xbox, but the site is not Xbox-only.

Business goals: independent sustainable revenue, COZMC community growth, future Nerdy Birdie membership benefits. Journey: search/social/video → useful free guide → saved progress and repeat visits → optional Discord or COZMC website → optional Algorand/COZMC education and approved premium tools later. No misleading affiliation, token pressure or required wallet. "Play Smarter. Discover More." is a proposed tagline, not final approval.

## Core launch scope (subject to founder approval and verified content availability)
- Home with featured game, game library, guide categories, resume progress, search and COZMC community panel.
- Game overview and platform selector using only officially supported platforms for that title. Architecture supports Xbox Series X|S, Xbox One, PS5, PS4, PC and future Nintendo/other systems. Verify GTA VI availability independently; do not present PS4/PC as playable unless officially confirmed. Platform-independent guide content can be reused; platform-specific controls, achievements, trophies and performance instructions remain distinct. No fabricated release dates or requirements.
- Manual achievement/trophy tracking; separate official platform lists, in-game completion and unofficial challenges. Stable IDs, overall/category progress with clear denominators, filters, bookmarks, notes, reset confirmation, versioned local persistence, export/import with validation and migration. Separate game and platform progress; explicit mapping for shared objectives. No claim of console synchronization. Empty categories are not 100% complete. Explain local-only data and backup options.
- Spoiler modes: default spoiler-free; minor gameplay spoilers; all spoilers; optional verified story progression. Use safe titles and placeholders; explicit reveal, no sensitive image thumbnails/alt text, search snippets, map markers, autocomplete, links or metadata leakage. Hidden objectives may contribute to totals without revealing details; avoid hidden clues via URLs. No spoiler content embedded in publicly indexed metadata. Client-side concealment is an experience feature, not a security boundary.
- Verified starter guides: money (in-game only, mode and patch), rare vehicles/weapons (fictional gameplay only), collectibles, hidden locations, settings, tips, mission/side mission info only when safe and verified. Time/difficulty/rarity/returns labeled with evidence and uncertainty. YouTube click-to-load embeds, creator credit, verified URL and timestamp, fallback external link, no autoplay. Hide unapproved/unverified content by default.
- COZMC Discord and cozmc.us distinct links in desktop header, mobile navigation, home community module, relevant guide invitations and footer; no intrusive overlays. Discord invite from authorized existing project context; otherwise unavailable state, release blocker for community link. No fabricated links. Parent brand link only once confirmed.
- About/unofficial disclaimer, privacy, contact/corrections, updates, clear sources and freshness. SEO semantic pages, safe metadata, canonical URLs, sitemap, internal linking, no low-quality mass pages. Staging noindex plus access restrictions if private; noindex is not access control.

## Later phases — not MVP commitments
Full map with licensed base art and separate coordinates, advanced 100% roadmap, expanded collectibles, community discoveries with moderation, founder-only Content Studio with secure authentication and draft/preview/revision/publish workflow, player accounts/cloud sync, advanced tracking/themes, memberships, creator partnerships and clearly disclosed sponsorship/affiliate links. Validate demand and permissions before monetization. Future optional Discord auth, Algorand wallet and token utility require separate security/abuse review and approval; only then use TestNet. Manual checkboxes cannot be evidence of token rewards. No keys in frontend, no real transactions. Education includes custody, fees, scams and risk; never promise returns. Separate personal, employer, member and COZMC data.

## Measurement
Primary early signals: returning visitors, tracker use, guide usefulness and accuracy. Secondary: organic discovery, link clicks, actual joins only if independently measurable, later conversion. Propose privacy-respecting analytics and consent before adding tracking. Do not equate clicks with joins. Maintain corrections log and source recheck cadence.
